# История доставок и самовывозов

`GET /protected/delivery-history` — авторизованный запрос без изменения документов,
блокировок редактирования и событий аудита.

Обязательные `date_from`, `date_to` ограничивают плановую дату, включительно.
Максимум — 12 календарных месяцев: с 01.01.2026 по 31.12.2026,
с 29.02.2024 по 28.02.2025. Некорректный период возвращает 422.
`offset >= 0`, `limit` от 1 до 100 (по умолчанию 25).
Сортировка: плановая дата, время создания, ID документа по убыванию.

`search` (до 500 символов) ищет подстроку текущего имени или адреса клиента
без учёта регистра либо цифры в нормализованном телефоне. `%`, `_`, `\` —
буквальные символы. Деактивированные клиенты участвуют в поиске.
Анонимные покупки не совпадают с поиском клиента. Пустой поиск возвращает
все документы периода, включая пустые и анонимные.
`include_cancelled=false` по умолчанию скрывает отменённые документы.

Ответ — стандартный envelope с `offset`, `limit`, `total`, `data.documents`.
Одна запись — целый документ: `deliveryDocumentId`, `documentType`
(`deliveryRouteSheet` / `pickupSheet`), `plannedDate`, `createdAt`, `isActive`,
`driverName`, `carModelAndNumber`, `clientsCount`, `purchasesCount`, `totalAmount`,
`matchedClients`. Сумма и количество всегда относятся ко всему документу.
Количество клиентов — число покупок маршрута; покупки самовывоза считаются отдельно.

При непустом поиске `matchedClients` содержит отдельную запись для каждой
совпавшей покупки: `pointId`, `clientId`, `clientName`, `address`, `phone`,
`paymentMethodId`, `paymentMethodName`, `totalAmount`, `items`.
В `items`: `itemId`, `productId`, `productName`, `quantity`, `price`, `amount`,
`isFreePrice`, `driverNote`. Уточнение доступно в подробностях покупки.
Покупка также содержит `isDelivered`, `nonDeliveryReason`: попытка неудачной
доставки остаётся доступной в истории с суммой заказа, но её сумма исключена
из `totalAmount` документа. См. [правила недоставки](failed-delivery.md).
Названия товаров, цены и способ оплаты взяты из сохранённой покупки;
название способа оплаты — из связанного справочника. Денежные значения —
десятичные строки, сумма строки округлена до копеек перед сложением.
При пустом поиске `matchedClients=[]`. Документы не дублируются при нескольких совпадениях.

Flutter: вкладка «История доставок», заголовок «История доставок и самовывозов».
Период по умолчанию — последние 30 календарных дней, включая сегодня;
сброс восстанавливает его, очищает поиск и скрывает отменённые.
Карточка открывает документ; вложенный блок клиента открывает подробности
его покупки отдельным диалогом. Период обязателен при любых фильтрах.
Новая миграция не требуется: добавляется только чтение существующих таблиц.

Это контракт текущего общего экрана. Предлагаемое разделение на «Историю клиентов»
и «Историю документов» ещё требует отдельного согласования; новые режимы API
в рамках исправлений свободной цены не добавляются.
