# Контракт API товаров для Flutter

Статус: API уже реализован в FastAPI; документ фиксирует его текущий контракт и
область интеграции Flutter. Правила API сверены с `src/feat/products/api/`.

## Авторизация и общий формат

- Все запросы требуют авторизации. Flutter передаёт `Authorization: Bearer <accessToken>`.
- Базовый путь: `/protected/products`.
- JSON использует `camelCase`; успешный ответ обёрнут в `StdResponse` с полезной
  нагрузкой в `data`.
- Идентификатор товара — UUID в виде строки.
- Поля `productId`, `createdAt` и `isActive` назначаются сервером при создании.

## Эндпоинты

| Метод и путь | Назначение | Тело / параметры | Результат |
| --- | --- | --- | --- |
| `GET /protected/products` | Список товаров | `include_deactivated` (query, по умолчанию `false`) | `data.products: Product[]` |
| `GET /protected/products/{product_id}` | Товар по UUID | UUID в пути | `data: Product` |
| `POST /protected/products/create` | Создать товар | `{ "name": string, "basePrice": number }` | HTTP 201, `data: Product` |
| `PATCH /protected/products/{product_id}` | Изменить товар или активность | Любое непустое подмножество `name`, `basePrice`, `isActive` | `data: Product` |
| `GET /protected/products/check-duplicate?name=...` | Найти похожее имя | `name`, длина 1–120 | `data: Product` или `null` |

Схема `Product`:

```json
{
  "productId": "uuid",
  "name": "Вода 19л",
  "basePrice": 100.0,
  "createdAt": "2026-10-12T10:00:00Z",
  "isActive": true
}
```

## Правила и ошибки

- `name`: от 1 до 120 символов. `basePrice`: от 0 до 1 000 000 000.
- Список по умолчанию содержит только активные товары. `include_deactivated=true`
  добавляет деактивированные записи.
- Получение по ID возвращает товар вне зависимости от `isActive`.
- Товар не удаляется физически. Деактивация и повторная активация выполняются
  через `PATCH` с `{"isActive": false}` или `{"isActive": true}`.
- Точное имя уникально с учётом регистра и без нормализации пробелов. Создание
  или переименование в занятое имя возвращает HTTP 409.
- Проверка дубликатов — подсказка: ищет похожее имя с порогом similarity 0.35
  среди активных и деактивированных товаров и не блокирует похожее имя.
- Пустой `PATCH` и значения вне ограничений возвращают HTTP 422; неизвестный
  UUID возвращает HTTP 404; без авторизации API возвращает HTTP 401.

## Область интеграции Flutter

Flutter уже использует один `ProductRepository` в выборе позиций маршрутного
листа, подборе товаров для выдачи и редакторе товара. Подключение этого
репозитория к API затронет все эти места. Идентификаторы каталога и ссылки в
позициях маршрутных/выдачных документов переходят с `int` на UUID-строку.

Сводки дней доставки остаются demo-данными с отдельным числовым `productId`.
Эти ID не сопоставляются с UUID серверного каталога, поэтому количества из
старых demo-сводок не связываются с товарами API до подключения API дней доставки.

## Подтверждённые решения интеграции

1. Похожие названия можно сохранять. Подсказка `/check-duplicate` не блокирует
   отправку формы. Точное совпадение имени отклоняется API с HTTP 409 и должно
   отображаться как ошибка сохранения.
2. Вместо удаления Flutter вызывает деактивацию. В интерфейсе будет переключатель
   показа деактивированных товаров и действие их повторной активации.
   Селектор использует тот же flow, что автомобили и водители: постоянные кнопки
   «показать неактивные → редактировать → создать», недоступные действия отключены.
   Выбор неактивного товара предлагает «Активировать и выбрать»; отмена сохраняет
   предыдущий выбор. Найденный похожий товар можно выбрать или открыть в редакторе.
3. Старые локальные demo-документы с числовыми product ID после перехода на API
   маршрутов и выдач не поддерживаются. Ссылки в новых документах используют
   UUID-строки. Сводки дней доставки остаются отдельным demo-источником и их
   числовые товары не связываются с серверным каталогом.

Уникальность имени следует текущему правилу backend: точное совпадение
регистрозависимое, пробелы не нормализуются. Например, `Вода` и `вода` считаются
разными именами; это поведение отражает контракт API.
