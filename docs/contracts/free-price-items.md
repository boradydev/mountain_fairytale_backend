# Свободная цена и уточнение строки маршрута

Статус: backend-контракт и миграция, форма товара, цена/уточнение в маршруте
и печатная форма подготовлены локально. Остались фильтрация отчётов и
поддержка нескольких свободно оцениваемых строк одного товара в одной точке.

## Каталог товаров

Товар содержит `isFreePrice`, по умолчанию `false`. Для товара со свободной
ценой `basePrice` сохраняется как `0`; backend устанавливает ноль при создании
или включении признака. Ограничение базы запрещает свободной позиции иметь
ненулевую цену каталога.

## Строка документа

Строка содержит снимок `isFreePrice` и `driverNote` длиной до 1000 символов.
Снимок не меняется при последующих изменениях товара в каталоге. Уточнение
принадлежит товарной строке конкретного клиента в конкретном маршрутном листе.
Уточнение разрешено только для свободной по цене позиции.

Цена строки остаётся числовой и обязательной; для ещё не оценённой свободной
позиции используется `0`. В отчётах свободная позиция с нулевой ценой не должна
учитываться; позиция с ненулевой ценой учитывается. Это правило ещё предстоит
добавить в запрос отчёта. Новые поля доступны в ответах документа, списка
документов дня и истории.

Для самовывоза свободная цена и уточнение маршрута запрещены. Старые товары и
строки получают `isFreePrice: false` и пустой `driverNote`.

## Несколько строк одного свободного товара

В одной точке маршрута обычный товар остаётся единственной строкой. Товар со
свободной ценой можно добавить несколько раз; каждое добавление — отдельная
строка с собственными количеством, ценой и уточнением. Самовывоз по-прежнему не
принимает такие товары.

Это требование пока не реализовано. Текущая таблица использует первичный ключ
`(point_id, product_id)`, API запрещает повторный `productId`, а журнал событий
идентифицирует строку по паре точки и товара. Для отдельных строк нужен
постоянный `itemId`: его надо добавить в модель и API, использовать при
обновлении и в аудите, а существующим строкам назначить в SQL-миграции. Flutter
должен использовать этот ID как ключ строки и разрешать повторное добавление
только для свободно оцениваемых товаров.

## Сводка загрузки со склада

В печатной форме раздел называется «Загрузить со склада». В него входят обычные
товары, включая товары с нулевой ценой; все строки со свободной ценой исключены
независимо от цены. Точки с неудачной доставкой остаются в сводке, так как товар
мог быть загружен до попытки доставки.

## Запросы

Создание товара принимает необязательный `isFreePrice` (по умолчанию `false`).
При `true` цена каталога становится `0`. PATCH принимает `isFreePrice`; при
включении признака цена каталога также становится `0`.

Создание строки документа принимает `isFreePrice` и `driverNote`. Признак новой
строки должен совпадать с текущим признаком товара в каталоге. При обновлении
существующей строки признак передаётся как неизменяемый снимок; его можно не
передавать для сохранения совместимости со старыми клиентами. Отсутствующее
уточнение при PATCH сохраняет уже записанный текст.

## Миграция

Ревизия `4d8b3f7a1c2e` следует за `f61da2e3b780`. Upgrade добавляет признак
каталога и поля строки с безопасными значениями по умолчанию. Downgrade
останавливается, если уже существуют свободные товары или строки с уточнениями,
чтобы не удалить используемые данные молча.
