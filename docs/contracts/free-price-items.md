# Свободная цена и уточнение строки маршрута

Статус: этап 1 — backend-модель, API и миграция подготовлены локально.
Этапы интерфейса маршрута, печати и расчётов выполняются отдельно.

## Каталог товаров

Товар содержит `isFreePrice`, по умолчанию `false`. Для товара со свободной
ценой `basePrice` сохраняется как `0`; backend устанавливает ноль при создании
или включении признака. Ограничение базы запрещает свободной позиции иметь
ненулевую цену каталога.

## Строка документа

Строка содержит снимок `isFreePrice` и `driverNote` длиной до 1000 символов.
Снимок не меняется при последующих изменениях товара в каталоге. Уточнение
принадлежит товарной строке конкретного клиента в конкретном маршрутном листе.
Уточнение разрешено только для свободной по цене позиции.

Цена строки остаётся числовой и обязательной; для ещё не оценённой свободной
позиции используется `0`. Это изменение не меняет правила отчётов: исключение
нулевой свободной цены выполняется следующим этапом. Новые поля доступны в
ответах документа, списка документов дня и истории.

Для самовывоза свободная цена и уточнение маршрута запрещены. Старые товары и
строки получают `isFreePrice: false` и пустой `driverNote`.

## Запросы

Создание товара принимает необязательный `isFreePrice` (по умолчанию `false`).
При `true` цена каталога становится `0`. PATCH принимает `isFreePrice`; при
включении признака цена каталога также становится `0`.

Создание строки документа принимает `isFreePrice` и `driverNote`. Признак новой
строки должен совпадать с текущим признаком товара в каталоге. При обновлении
существующей строки признак передаётся как неизменяемый снимок; его можно не
передавать для сохранения совместимости со старыми клиентами. Отсутствующее
уточнение при PATCH сохраняет уже записанный текст.

## Миграция

Ревизия `4d8b3f7a1c2e` следует за `f61da2e3b780`. Upgrade добавляет признак
каталога и поля строки с безопасными значениями по умолчанию. Downgrade
останавливается, если уже существуют свободные товары или строки с уточнениями,
чтобы не удалить используемые данные молча.
