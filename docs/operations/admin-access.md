# Восстановление доступа администратора

Если забыли логин или пароль администратора, используйте CLI на сервере.
Действующий вход в приложение и старый пароль для этого не нужны.
CLI работает с базой из настроек запуска и находит администратора по роли
`admin`, независимо от его текущего логина и `ADMIN_USERNAME` в ENV.

## На сервере в Docker

Подключитесь к Ubuntu VM по SSH и перейдите в каталог приложения:

```sh
cd /opt/mountain-fairytale
```

Узнать текущий логин и активность учётной записи:

```sh
sudo docker compose exec api python -m src.common.cli.main admin info
```

Пример вывода после переименования администратора:

```text
Логин администратора: Администратор
Учётная запись активна: да
```

Задать новый пароль:

```sh
sudo docker compose exec api python -m src.common.cli.main admin change-password
```

CLI сначала показывает, какой учётной записи меняет пароль:

```text
Смена пароля администратора: Администратор
Новый пароль:
Повторите новый пароль:
```

Ввод скрытый: символы пароля не отображаются. Введите новый пароль дважды.
При несовпадении пароль не изменяется; повторите команду.
Пароль не передаётся аргументом команды и не выводится после сохранения.
После сообщения об успешном изменении войдите в приложение с текущим логином
из `admin info` и новым паролем. Перезапуск API не требуется.

## Локальная разработка

Из корня backend-проекта, после установки зависимостей и настройки `.env`:

```powershell
poetry run python -m src.common.cli.main admin info
poetry run python -m src.common.cli.main admin change-password
```

Если виртуальное окружение уже активировано, вместо `poetry run python`
можно использовать `python`. CLI загружает `.env`; уже заданные переменные
окружения имеют приоритет. Проверьте, что запускаете команду для нужной базы.

## Что важно знать

- `admin info` только читает данные. Он не показывает пароль или его хеш.
- `ADMIN_USERNAME` и `ADMIN_PASSWORD` используются при первоначальном создании
  администратора. Изменение `.env` и перезапуск API не переименуют существующую
  учётную запись и не сбросят её пароль.
- Переименование администратора не мешает CLI: поиск выполняется по роли.
- Смена пароля не меняет логин или активность учётной записи и не отзывает
  ранее выданные токены. Это восстановление пароля, а не принудительный выход
  из всех сессий.
- Если администратор не найден, CLI сообщает об ошибке и не создаёт нового.
  Проверьте выбранную базу и успешность первоначального запуска API.
