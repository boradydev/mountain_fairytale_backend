# QA-002 — редактировать тот же маршрут

Нужен PASS QA-001; новый документ не создавать.

```powershell
.\scripts\qa\qa.ps1 scenario-prepare QA-002
```

1. По выданному UUID и дате **08.11.2026** открыть маршрут QA-001 во Flutter.
   Сверить памятку текущего цикла. Нажать **Редактировать**.
2. У клиента **QA-MANUAL-21** изменить количество Товар-1 **2 → 3**;
   цену свободного Товар-8 **12,50 → 19,90**. Уточнение сохранить.
3. Визуально проверить сумму первой точки **79,90**, второй **90,00**,
   итог маршрута **169,90 ₽**. Клиента 22, оплаты, дату, машину, водителя,
   памятку, порядок и остальные строки не менять.
4. Нажать **Сохранить**, дождаться режима просмотра и уведомления успеха.
   Повторно открыть маршрут и убедиться, что изменения сохранены.

```powershell
.\scripts\qa\qa.ps1 scenario-verify QA-002
```

PASS подтверждает сохранение UUID документа, обеих точек и всех строк,
снимков и ставок, revision +1, аудит и новые точные комиссии:
rep0 **5.9925**, employee0 **2.12375**. Визуальное поведение подтвердить отдельно.
FAIL: сохранить диагностику; не создавать замену и не править SQL. При
сетевой ошибке повторить verify. Инструкция снова доступна через
`scenario-status QA-002`. После PASS переходить к QA-003.
