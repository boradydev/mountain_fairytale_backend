[Инструмент, журнал и повторные запуски](../stages/03-scenarios-verification.md).
Flutter использует человек; проверяющий читает API/SQL и не создаёт документы.

| Сценарий | Зависимость | Действие | Итог |
| --- | --- | --- | --- |

| [QA-002](QA-002-edit-delivery.md) | PASS QA-001 | Изменить количество и свободную цену того же маршрута | 169,90 ₽ |
| [QA-003](QA-003-failed-delivery.md) | PASS QA-002 | Отметить точку 21 недоставленной | 90,00 ₽ |
| [QA-004](QA-004-anonymous-pickup.md) | Нет | Создать три покупки самовывоза 09.11.2026 | 120,00 ₽ |

Для каждого: `qa.ps1 scenario-prepare QA-...` → ручные действия →
`qa.ps1 scenario-verify QA-...`. Состояние: `qa.ps1 scenario-status`.
Повтор инструкции: `qa.ps1 scenario-status QA-001`.

Не выполнять очистку постоянной QA и не удалять документы ради повтора.
Явный новый цикл: `qa.ps1 scenario-prepare QA-001 -NewCycle`, с сохранением
всей прежней истории. Запущенный сценарий без этого флага не перезаписывается.

Отчёт проверки не должен объявлять UI/PDF пройденными, если автоматом
проверена только база данных. Визуальные проверки требуют отметки владельца.
