# Планы этапов QA

Главная стратегия: [../README.md](../README.md).  
Текущий статус: [../progress.md](../progress.md).

Здесь появляются **подробные задания только для согласованного ближайшего
этапа**. Все шесть этапов и критерии их завершения уже перечислены в общей
стратегии, поэтому не нужно заранее создавать шесть больших технических
заданий.

Рекомендуемые имена: `01-environment.md`, `02-seed-data.md`,
`03-scenarios-verification.md`, `04-functional-acceptance.md`,
`05-resilience-load.md`, `06-release-readiness.md`.

Каждый документ этапа должен содержать цель, границы, входные условия,
конкретные действия Codex и владельца, команды/инструменты, ограничения
безопасности, критерии приёмки, ссылки на тесты и формат итогового отчёта.

**Планы этапов пока не подготовлены и не утверждены.**
