# Отчёты QA

Главная стратегия: [../README.md](../README.md).  
Прогресс и дефекты: [../progress.md](../progress.md).

Здесь храним **небольшие текстовые отчёты** о завершённых этапах и о ручных
QA-прогонах. Не храним в Git дампы PostgreSQL, пароли, токены, подробные
логи с персональными данными, массовые выгрузки и бинарные результаты.

Рекомендуемое имя отчёта: `YYYY-MM-DD-stage-N.md` или
`YYYY-MM-DD-QA-001.md`.

Минимальный состав:
- Дата, среда и версии (backend/Flutter/ревизия Git и Alembic).
- Пройденные ручные шаги, исполнитель и автоматические команды.
- Результаты PASS/FAIL/SKIP с ожидаемыми и фактическими значениями.
- Ссылки на сценарии, дефекты, регрессионные тесты и изменения.
- Известные ограничения и решение владельца о приёмке этапа.

**Фактических QA-отчётов по этой стратегии пока нет.**
