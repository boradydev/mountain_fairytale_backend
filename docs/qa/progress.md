Заблокирован**. Указывать дату и подтверждающие артефакты при смене статуса.
«Завершён» означает принятие этапа владельцем, а не только сообщение Codex
об успешном выполнении команд.

## Принятые решения

- 06.11.2026 — стратегия шести этапов согласована.
- Обязательное сочетание: тестовая база + сценарии действий оператора во
  Flutter + автоматическая сверка через API/SQL.
- Среда Windows 10 с локальными PostgreSQL и FastAPI уже доступна;
  WSL/Docker — дополнительная возможность. Конкретный способ изоляции
  выбирается на этапе 1.
- Рабочие данные и существующие pytest-базы не затрагивать.
- Подробные этапные задания готовятся непосредственно перед исполнением.

## Дефекты

Формат записи после обнаружения:
- `BUG-001` / дата / связанный сценарий `QA-...` / важность.
- Что сделали, ожидалось, получилось; идентификаторы тестовых объектов.
- Диагностика и решение, ссылки на коммиты и регрессионный тест.
- Состояние: открыт / исправлен / повторно проверен / отложен.
