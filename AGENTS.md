# Доступ к локальной базе данных

- В этом проекте локальный PostgreSQL доступен по адресу `127.0.0.1:5432`.
- Пользователь разрешил использовать пароль для разработки `postgres` и подключаться напрямую к локальной базе разработки/тестирования без повторного запроса разрешения.
- По необходимости задачи можно просматривать эту тестовую базу и создавать в ней тестовые записи. Проверяй успешность записи, прочитав её обратно из базы.
- Тестовый набор может пересоздать базу, поэтому тестовые данные временные. Не удаляй, не пересоздавай и не сбрасывай базу вне штатного тестового процесса проекта.

# Запуск pytest из Codex

- Запускай pytest из корня проекта в PowerShell через локальное окружение `.venv\Scripts\python.exe`, направляя временные файлы в `.codex-tmp` и явно задавая `--basetemp=.codex-tmp\pytest`; не используй Poetry или пользовательскую Temp-папку.
- Перед запуском выполни:

  ```powershell
  $codexTmp = Join-Path (Get-Location) ".codex-tmp"
  New-Item -ItemType Directory -Force -Path $codexTmp | Out-Null
  $env:TEMP = $codexTmp
  $env:TMP = $codexTmp
  .\.venv\Scripts\python.exe -m pytest --basetemp=.codex-tmp\pytest
  ```
- Для запуска конкретных тестов добавь их пути перед `--basetemp`, сохранив переменные окружения.
- Если `.venv\Scripts\python.exe` отсутствует, сообщи об этом и не устанавливай зависимости без отдельного запроса.
